# 📊 Excel Data Analysis Project
### Data Technician Bootcamp | Retail & Sales Analytics

## 🚀 Project Overview

As part of my **Data Technician Bootcamp**, I completed a hands-on Excel project focused on analysing retail and sales datasets. The project involved cleaning data, applying formulas, creating PivotTables, and building visual reports to uncover business insights and support data-driven decision-making.

---

## 🛠️ Skills & Techniques Used

### 🧮 Excel Formulas & Functions
Applied a range of essential Excel functions to perform calculations, automate analysis, and transform data:

| Function | Purpose |
|-----------|----------|
| `SUM()` | Calculate total sales and commission values |
| `SUMIF()` | Sum values based on specific criteria |
| `AVERAGE()` | Calculate average sales figures |
| `AVERAGEIF()` | Calculate conditional averages |
| `DATE()` | Create and manipulate date values |
| `MONTH()` | Extract month information from dates |
| `YEAR()` | Extract year information from dates |
| `UNIQUE()` | Generate lists of distinct values |
| `VLOOKUP()` | Match and retrieve data from lookup tables |
| `SWITCH()` | Categorise products based on sales performance |

### 📂 Data Preparation
